Design notes for review
  • Un-lumped at the source view (v6ui_itemrollintegritydialog), added additively — the old Comment stays for V7 / the usp6 sproc; V8 just shows the three new columns instead.
  • Reset row → banner. The view's synthetic Reason='Reset:' row is shown as the strip at the top (the date variance is measured from), not as a fake item row.
  • "Check Integrity 4" flag rows still carry Last Activity / Tx Count / QOH (V7 hid those when the flag fired) — strictly more information.
  • Sortable grid. Every column heading is click-to-sort (toggling asc/desc); default is largest AdjAmount first. New today — the current modal renders a fixed |AdjAmount| order with non-clickable headers. Un-lumping is what makes sorting by Tx Count / QOH / Last Activity useful. Sort is client-side on the rows already loaded.
  • Company + account filters apply — already true today. The page's company / business-unit / object / subsidiary selection narrows the rows server-side (the agent passes the reconciliation filter to the view; period is dropped since cardex is current-state), on top of JWT company scope, and the modal re-applies the company + in-scope-account filter client-side. The footer states the active scope.
  • Cost Level added. The item's JD Edwards cost level (1 = item, 2 = item/branch, 3 = item/branch/location/lot) from ritems — already joined in the view, so it's a free add. Surfaced for Daren's rule review (it's a contributor there); useful setup context for Karen too.
  • Karen vs Daren. This modal is awareness + export only. The cost re-roll workflow stays on the dedicated Cardex Variance page (Daren) — which adopts these same columns next.
