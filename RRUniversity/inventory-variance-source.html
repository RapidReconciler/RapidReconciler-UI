Variance Sources

One page per source of inventory variance. Each shows the rows that make up that source’s total, so you can see what to clear and who usually clears it.

Product: RapidReconciler V8 Module: Inventory Press Ctrl+F (or ⌘+F) to search this page

What the page shows

The page shows one source at a time. Which one depends on the source value in the page address, and the page title changes to match it. The values are carryForward, glBatches, endOfDay, transactions, cardex and manualJournalEntries. Any other value, or none, shows Unknown variance source and no grid.

The page takes nothing else from the address. The companies are the ones you’re working in on Home, and the period is the one you’re working in on this database.

The dot before the title turns green when the source nets to zero, meaning it adds nothing to the variance. Otherwise it stays grey, because a non-zero total is what the page is there to explain.

If RapidReconciler can’t read the source, a red banner starting Couldn’t reach the data service appears, This source shows a dash, and the grid stays empty. That doesn’t mean there is nothing to reconcile. Try again, and if it keeps happening, ask your IT department to check that the data service is reachable.

The five sources

The page title names the source, and the line under it describes it. The Owner fact names the next step and who usually takes it.

Carry forward

The variance left unreconciled at the end of the period before the one you’re working in. The grid lists how that earlier period’s variance was made up, one row per component: Carry forward, GL batches, Orders (end of day), Transactions, Cardex and Manual journal entries. The line under the title adds which period that is and the period it was carried into.

The components carry different sign conventions, so they don’t add up to the total. This source shows the earlier period’s unreconciled variance itself. When the period you’re working in is the earliest one in the data, there is nothing to carry forward, and the page says so.

GL batches

General ledger lines on inventory accounts that haven’t posted yet.

Orders

Item-ledger rows that aren’t in a GL batch yet, so the cardex has moved and the general ledger hasn’t.

Cardex

Items whose on-hand balance doesn’t match their item ledger, measured from the date the cardex was last reset. This is a picture of today, so it doesn’t follow the working period.

Journal Entries

Manual journal entries posted straight to inventory accounts, with no order behind them.

Transactions

The Transactions source (item ledger to general ledger discrepancies) has its own page. If you open this page for transactions, it goes straight to Transaction Details instead, keeping the rest of the address.

The facts strip

The strip under the title states what the grid covers.

  • This source: the source’s total. For every source except Carry forward, it’s the sum of the amount column over all its rows, whatever you’ve filtered. Negative amounts are in parentheses.
  • Working period: the period you’re working in on this database, carried over from the page you came from. Cardex always shows Current.
  • Companies: how many companies you’re working in, for example 3 selected.
  • Database: the RapidReconciler database you’re signed in to.
  • Owner: the next step for this source, with a tag naming who usually takes it.

The detail grid

The grid is titled with the source’s name followed by detail, for example GL batches detail.

  • Filter rows…: shows only rows with the text in any column.
  • Export: downloads the rows you’re looking at to Excel, in your sort order. The headers use the full column names. The top of the file names the source, the database, the companies and the period, plus your filter text if there is one, and the last row is a total.
  • Click a header to sort by it. Click again to reverse the sort.

The total row

The row under the grid carries a total in the amount column. With no filter, it matches This source. With a filter, the row is labeled Filtered subtotal and totals only the rows you can see. Carry forward can’t give a subtotal, because its rows don’t add up to its total, so a filtered Carry forward grid shows no figure and points you to This source.

The Cardex was reset banner

On the Cardex source, a banner above the grid starting Cardex was reset shows when the cardex has a reset on record. The figures in the grid run from that reset forward.

When a source has no rows for the companies and period you’re working in, the grid reads No rows for this source in the current scope.
