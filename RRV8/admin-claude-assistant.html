How each level answers

Take one finding — a −1,240.50 difference on an inventory account in period 2026-05. Here’s how the assistant answers the same question at each level:

Off

Docs-grounded

General guidance from the help library — none of your figures are used.
Scrubbed analysis
“This −1,240.50 offset in 2026-05 looks like a GL-class change: the item moved cost categories mid-period, leaving the two accounts unbalanced. Post a reclassifying entry between them.”
Your numbers and the pattern — account, company, and item identifiers removed first.
Full data
“The −1,240.50 offset is a GL-class change on account 5000.140000 — item MFG01 changed class on 2026-05-14. Reclassify 1,240.50 to 5000.141000 to clear it.”
The actual rows, so the fix names the account and item.
