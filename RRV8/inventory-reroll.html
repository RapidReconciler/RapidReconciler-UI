Re-roll Companies

Recompute the perpetual inventory balance from the baseline date forward for the companies you choose, then rebuild the account roll-forward so the report reflects it. This settles most variance breaks. It runs for a few minutes and changes nothing in JD Edwards.

Re-rolling is a reconciliation function. Contact your administrator if you need access.
The database is busy. Another process is running, so a re-roll is paused until it finishes. This re-enables on its own.
This recomputes RapidReconciler’s working balance — it does not pull from or write to JD Edwards. A re-roll and a data refresh / deploy can’t run at the same time, so it’s safe to run whenever the database is idle.
