Period-End Date Correction

When a fiscal-calendar change moves a period-ending date, the reporting tables keep the old date until it’s corrected. This replaces the old date with the corrected one everywhere it’s stored, for all companies.

This is an administrator function. Contact your administrator to correct a period-ending date.
Use this only after a confirmed fiscal-calendar change — for example, an acquisition that re-bases a period boundary. Load the corrected calendar first, then run this. Preview before you apply.
Step 1Check for a mismatch

Compares the latest stored period-ending date against the fiscal calendar. If the stored date is no longer in the calendar, it’s the one to correct.
