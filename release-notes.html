What’s new in RapidReconciler.

Newest changes appear at the top — each entry is auto-published from a merge to main. Spot something missing or want context on a fix? rrsupport@getgsi.com.

August 9, 2026

Fixed a fault that could leave the Home page blank after a refresh.

August 9, 2026

The Data Health tab now opens with your model table: the document type it uses, how many GL classes route through it and to how many accounts, and how much sits outside it -- with the routing list one click away. It previously counted routings under document types your company does not use, so the figures were higher than your model actually is and did not match the Model DMAAI Review page. They agree now, because both read the same source.

August 8, 2026

Excel exports across RapidReconciler are now built from a single shared template, so every workbook you download looks the same. One export was also forcing all numeric columns to two decimal places regardless of the column; unit costs and other fine-precision figures now export at the precision they are shown.

August 8, 2026

The help panel on Accounting Model Review now opens documentation written for the question that page asks -- what it means when a GL class code is missing from your model, how to tell a genuine exclusion from real stock that has fallen out of reconciliation, and why those two need opposite fixes. It also documents, for the first time, how to mark a class as a deliberate exclusion in JD Edwards itself using a DMAAI 4152 entry with document type 98, so the decision travels with your own configuration.

August 8, 2026

The AI reads across RapidReconciler now speak with one voice, and each one leads with what the figures mean and what to do about them rather than with the mechanism. Where an answer carries more than one point it now comes back as separate lines instead of a paragraph you have to re-read to separate, and the answers that were cut too short to fit a recommendation have room for one.

August 8, 2026

The model review page now judges each excluded GL class from what its items actually hold -- stocking type, unit cost, quantity on hand, and whether the branch and location classes agree -- instead of from the class code. Where a class holds value it tells you which of the two possible causes fits and what to check, because the two have opposite fixes: adding the class to your model table is right for stock that is wearing the wrong class, and wrong for an item that should never have held a balance at all.

A class showing 0.00 is no longer treated as settled. If its items carry a unit cost, it is empty rather than free and will start excluding value on the next receipt. If it holds quantity with no cost anywhere, that is a costing gap, and it now says so on the row.

August 8, 2026

On the excluded GL class codes card, a class showing no value is now marked when the items behind it still carry a unit cost. Those exclusions read as zero only because nothing is on hand at the moment, and they will begin holding value once stock arrives -- unlike items that genuinely carry no cost, which can be set aside safely.

August 8, 2026

The excluded GL class detail now shows each item's unit cost alongside its quantity and value. This distinguishes an exclusion that currently holds no value because there is nothing on hand from one that holds no value because the item genuinely carries no cost -- only the second is safely set aside. Unit costs display to four decimal places so small per-unit costs are not rounded away.

August 8, 2026

The excluded GL class detail now shows each item's location and lot, and both of its GL class codes -- the one on the item location and the one on the item branch. Where those two differ, some of an item's movement can post to a different account than the rest, which is worth knowing before deciding whether an exclusion is deliberate. A recorded decision is now also reopened if the items behind it change, not only if the value changes.

August 8, 2026

The excluded GL class codes card now tracks review progress. The summary reports how many classes still need a decision and how much on-hand value is still outstanding, rather than repeating the same totals no matter how much has been reviewed. Once every exclusion has been reviewed the page says so, while making clear that accepted value still sits outside the reconciliation until the class is added in JD Edwards.
