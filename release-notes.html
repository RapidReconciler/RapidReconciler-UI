What’s new in RapidReconciler.

Newest changes appear at the top — each entry is auto-published from a merge to main. Spot something missing or want context on a fix? rrsupport@getgsi.com.

August 25, 2026

The GL Class Integrity report now leads with the two GL classes it compares — the branch class and the location class, side by side. The computed mismatch label and the item-master class column have been removed; the check is about the branch and the location disagreeing, and those two values now sit together at the front of the table and of the Excel export.

August 24, 2026

The analyst day brief now follows the period you select on the Transaction Variance chart. Clicking a period re-reads the brief for that period instead of leaving the previous period's wording on screen.

August 21, 2026

Correction to the provisioning and installation-prep guides. For Oracle and AS/400 sources, the server that runs Integration Services needs BOTH the 32-bit and the 64-bit client driver, in the same install location: the 64-bit driver runs the nightly extract, and the 32-bit driver is what the Integration Services designer uses if your install needs it. An earlier note today said only the 64-bit driver was needed — please disregard that. Visual Studio remains something to install only if GSI asks for it during your install, not part of the up-front server build.

August 21, 2026

The install and server-migration documentation now states one minimum SQL Server version (2019 or later) instead of three different ones, and explains why RapidReconciler pins each database's compatibility level to 140 regardless of which SQL Server version you run.

August 21, 2026

Provisioning guide updated: Visual Studio is no longer a prerequisite for installing RapidReconciler. GSI now builds and deploys the Integration Services packages and the database schema for you, so there is nothing to design or publish on site. For Oracle and AS/400 sources, only the 64-bit client driver is needed on the server that runs Integration Services.

August 20, 2026

Switching companies on the analyst view now works reliably; the view could previously fall back to the first company without saying why. The Model DMAAI Review page no longer carries the sales routing pairs table -- that analysis lives with the transaction variance work.

August 19, 2026

The Balancing Entry action on a company card opens its entry on the card again, rather than switching you to the Accounts tab.

August 19, 2026

The accountant Reconciliation and Accounts views now show the full variance breakdown as a tie-out: every component, a total, and a confirmation that they add up to the out-of-balance. Building a period-end adjusting entry is now a single path from the company card, with Excel and PDF exports and an option to defer a carry-forward to a later period.

The audit report's Perpetual Details section now lists one line per item with its description, unit of measure, quantity and amount, rather than repeating each item once per lot with those columns blank. Each account starts on its own page and can be reached from the Account Summary. Totals line up under the figures they total.

The Residual Optimizer now recognises quantities that round to zero, so it finds the rounding dust an analyst can see on screen. The cutoff dial is available without running the optimizer first.

August 19, 2026

Cardex Variance now makes it obvious that recording a JDE fix and adjusting RapidReconciler are alternatives, not steps -- with the two paths named for the system that is wrong. Adjustments appear in the ledger immediately instead of after a page refresh. The help panel shows only the terms used on the page you are reading, and Cardex Variance now opens its own how-to. On Home, selecting a clean period shows that period instead of quietly falling back to another one, cleared checks are tinted green, and the sub-view tabs are easier to find.

August 19, 2026

On the Home reconciliation cards, when a company's six variance components do not add up to its out-of-balance, the card now shows the unexplained remainder next to them and the AI summary says the breakdown is incomplete. Previously the components were presented as a full explanation of the gap even when they did not account for all of it.
