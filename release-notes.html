What’s new in RapidReconciler.

Newest changes appear at the top — each entry is auto-published from a merge to main. Spot something missing or want context on a fix? rrsupport@getgsi.com.

October 26, 2026

The Analyst view's Model DMAAI Table band now links to the DMAAIs page, opening on its Model tab.

October 26, 2026
  • The Connection Check now tells a slow answer from a blocked connection. A check that answers late shows amber with the time it took. A check that gets no answer within 30 seconds shows red, with advice for your IT team.
  • While a check is still waiting for an answer, its row says so.
  • The Connection Check now tests each database's service port over HTTPS.
October 26, 2026
  • The Connection Check now finds your RapidReconciler server the same way the application does, so a working server no longer shows as unreachable on some setups.
  • The network diagram shows the name and IP address in each box, as far as they can be known, and explains that the server-side legs are checked only once your server is reached.
October 26, 2026
  • On the administrator's Home, the Data loads line on the Troubleshooting card now opens the Data Refresh page, where Refresh now pulls today's JD Edwards changes during close.
October 25, 2026
  • The Administrator view now has two tabs: Overview, the screen you know, and a Walkthrough. The Walkthrough takes you through looking after your instance step by step: licensing, your team, connections and data loads, the activity log and the AI plan. Each step highlights the card it is about and shows what that card says now.
  • Each Walkthrough step links to the RapidReconciler University guide that covers it.
October 25, 2026
  • The Analyst view has a Walkthrough tab. It takes you through a company's period step by step: checking the data, working and handing off transaction variances, cardex variances, the Tools shelf and the Audit Center. Each step opens the screen it is about and uses your own data.
  • Each Walkthrough step links to the RapidReconciler University guide that covers it.
October 25, 2026
  • RR University on the Home page now opens a search of the guides for your modules, so you can find help without leaving the app, with or without the AI assistant.
  • Each step of the Accountant Walkthrough ends with a Read more link to the guide that covers it.
October 24, 2026

The Accountant view's Walkthrough now shows each step's instructions, and this period's figures, as bullet points.

October 22, 2026
  • The Walkthrough on the Accountant view now names the exact button for each step, starts from the company you can work next, and has a Previous step button.
October 22, 2026
  • The Accountant view has a new Walkthrough tab: the steps to reconcile a period, explained with your own companies, each one taking you to the page it is about.
