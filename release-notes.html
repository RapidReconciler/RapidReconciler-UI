What’s new in RapidReconciler.

Newest changes appear at the top — each entry is auto-published from a merge to main. Spot something missing or want context on a fix? rrsupport@getgsi.com.

October 5, 2026
  • When the server turns down a request, the page now shows the server's own explanation, such as "That database is not on your account." or "The report engine didn't restart. Contact RR support."
  • Error messages no longer include the web address of the request.
October 5, 2026
  • When a page can't load something, its message now ends with a reference your IT department can find in the RapidReconciler server's log.
  • Administrator > Troubleshooting checks three more connections: the database server to JD Edwards, the agent service to GSI, and how long the server's security certificate has left.
  • Download diagnostics now includes the most recent lines of the server's own log.
October 4, 2026
  • The Restart button for the report engine now restarts it and tells you whether it worked.
October 4, 2026
  • Server Requirements now size the application server's memory by how many RapidReconciler databases you run.
  • New guidance for running the database and application roles on one server, including how much memory to leave SQL Server.
October 2, 2026
  • Administrators have a new Troubleshooting page. It checks the connection to the RapidReconciler server and its database, the nightly data refresh, the JD Edwards import and the last reconciliation run, and says what to do about anything it finds.
  • A Troubleshooting card on the administrator Home shows the result for each area at a glance.
  • Download diagnostics saves a workbook with the technical detail, ready to give to your IT department.
October 2, 2026

The RapidReconciler service login now gets narrower rights on SQL Server Agent: it can start and read its own refresh job, and no longer has general read access to the msdb database.

October 1, 2026
  • New Help Desk guide for when a RapidReconciler database reads offline, with the checks for your IT in order.
  • Excel export troubleshooting now starts with your browser's local network access setting.
September 29, 2026
  • Adding a team member now tells you whether the invite email is on its way or could not be sent.
September 29, 2026
  • The Administrator welcome checklist now reflects your database: a step shows as done only when it is, and anything still outstanding appears under "Not ready yet" with what to do next.
September 29, 2026

The install bundle is now a single download for your application server. There are no database scripts to run; GSI deploys the database once your database team has completed the one-time SQL Server preparation in the installation prep document.
