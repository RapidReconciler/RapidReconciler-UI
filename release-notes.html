What’s new in RapidReconciler.

Newest changes appear at the top — each entry is auto-published from a merge to main. Spot something missing or want context on a fix? rrsupport@getgsi.com.

August 8, 2026

The excluded GL class codes card now tracks review progress. The summary reports how many classes still need a decision and how much on-hand value is still outstanding, rather than repeating the same totals no matter how much has been reviewed. Once every exclusion has been reviewed the page says so, while making clear that accepted value still sits outside the reconciliation until the class is added in JD Edwards.

August 7, 2026

On the Model DMAAI Review page, excluded GL class codes are now broken out by stocking type so each can be reviewed and marked individually, rather than judging a whole class at once. Each row opens the items behind it, and both the individual list and the full set of excluded items can be exported to Excel. The page now explains that the excluded amount is what matters when deciding whether an exclusion is deliberate, and the AI assessment runs automatically instead of waiting to be asked.

August 6, 2026

The Transaction Variance cards on the analyst home page are now grouped and ordered the way the reconciliation itself runs -- linked transactions that are grouped and judged together, then single-document variances in the order they are identified, then anything no pattern matched. The former "Quick wins" grouping has been retired. Each group now explains what it holds, and the Transaction Overview summary is easier to tell apart from the cards beneath it.

August 6, 2026

Every transaction-variance pattern now reads the same name and the same explanation wherever it appears -- the card, the details view, the work panel and a saved finding. Several patterns that previously showed no explanation on the details view now carry the full description and corrective action, and the internal pattern number no longer appears above the pattern name.

August 6, 2026

The Data Health tab now always shows the model account-routing table, with the full routing list one click away -- previously it was only reachable when a routing needed attention. Transaction-variance cards on the home page now show the explanation written for that specific pattern instead of a generic one.

August 5, 2026

Every transaction-variance category now appears under its own name. Categories that the system had already identified were previously shown as unclassified because the screen did not yet recognise them.

August 5, 2026

Transaction Variance now applies every pattern check consistently on first open, rather than occasionally missing one depending on load timing. The analyst home page reports whether the account model finished loading. Cards completed by an analyst now read "Mark reviewed" and carry a stamp showing the finding has been handed to the Audit Center.

August 5, 2026

Transaction Variance adds two new cards. "Offsetting GL Entries" finds documents where the general ledger posted two entries that cancel each other and never reached the inventory account -- your profit and loss shows nothing, so only a ledger-to-sub-ledger comparison surfaces it. "Non-Stock Sales Lines" identifies non-stock cost posted into an inventory account and names the item setup that causes it. Card guidance across the analyst surfaces has also been corrected: where the general ledger does not agree with the item ledger, RapidReconciler now always tells you a correction is needed rather than describing the difference as expected.

August 3, 2026

- Transaction Variance drill-through now always matches the card you clicked. A card showing 39 rows opens 39 rows. - A link carrying an unrecognised category or an out-of-scope company now says so plainly instead of showing a wider set of rows that looks correct. - Accuracy checks that cannot be completed now report that they could not run, rather than reporting a clean result. - Switching database refreshes every figure on the page, including the AI briefing, so no value carries over from the previous database. - Findings are now written as an investigation report: what was checked, what was found, and what stops it happening again. - Excel exports match what is on screen, and each states the company and period it actually contains.

July 22, 2026

- Analyst home now opens on your first company and keeps your company selection while you work. - Switching databases returns you to the Data Health view. - Fixed the AI assistant on the Inventory As-Of screen.
